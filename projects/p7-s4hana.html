동화기업 2022.03 — 현재 AWS / SAP

S4HANA 고도화
AWS 인프라 지원

역할: SAP ERP 고도화 프로젝트 AWS 인프라 지원 담당

프로젝트 개요

동화기업의 기존 SAP ECC 시스템을 S/4HANA로 고도화하는 대규모 ERP 전환 프로젝트에서 AWS 인프라 지원을 담당했습니다.

S4HANA 고도화 전환 기간 동안 AWS 인프라를 안정적으로 지원하고, ERP 관통 테스트 환경 구성 및 반복 테스트를 효율적으로 지원하기 위한 EC2 스냅샷 기반 백업·복구 자동화와 RDS Aurora PostgreSQL 운영을 수행했습니다.

주요 수행 내용

  • AWS 인프라 지원: S4HANA 고도화 전환 기간 중 AWS 인프라 지원 및 운영 안정화
  • ERP 관통 테스트 환경: ERP 관통 테스트 환경 구성 및 반복 테스트 지원
  • EC2 백업·복구 프로세스: 테스트용 EC2 이미지 백업·복구 프로세스 수립
  • 스냅샷 정책 자동화: EC2 스냅샷 정책 설계 및 관리 자동화로 테스트 환경 신속 복원
  • RDS 운영: RDS Aurora PostgreSQL 운영 및 성능 모니터링
  • DB 복제 및 초기화: 테스트 환경 DB 복제 및 초기화 프로세스 운영으로 반복 테스트 사이클 단축
  • 모니터링: CloudWatch, CloudTrail 기반 인프라 상태 모니터링

기술 스택

클라우드AWS
DBRDS Aurora PostgreSQL
컴퓨트EC2 (스냅샷 기반 백업·복구)
모니터링CloudWatch, CloudTrail
보안Inspector, GuardDuty
서버 OSLinux, Windows Server

핵심 성과

ERP 전환

신속 복원
EC2 스냅샷 기반 백업·복구 체계 구축으로 테스트 환경 신속 복원 가능
자동화
반복 테스트 환경 자동화(스냅샷 정책, DB 초기화)로 테스트 사이클 단축 및 운영 효율화
안정 운영
Aurora PostgreSQL 운영 및 성능 모니터링으로 ERP 전환 기간 DB 안정성 확보
