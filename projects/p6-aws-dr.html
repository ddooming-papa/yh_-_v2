동화기업 2022.03 — 2022.08 AWS / DR

AWS MGN 활용
IDC-AWS 하이브리드 DR 구성

역할: IDC-AWS 하이브리드 DR 환경 설계 및 구축 담당

프로젝트 개요

동화기업 IDC의 온프레미스 서버를 AWS 클라우드로 복제하여, 재해 발생 시 빠르게 클라우드 환경으로 전환할 수 있는 DR(Disaster Recovery) 체계를 구축한 프로젝트입니다.

AWS MGN(Application Migration Service)을 활용해 온프레미스 서버를 실시간으로 AWS에 복제하고, Site-to-Site VPN으로 IDC와 AWS 간 네트워크를 연결했습니다. 총 6대(개발 2대 + 운영 4대) 서버에 대한 DR 환경을 구성하고 절체 테스트 시나리오를 수립·검증했습니다.

주요 수행 내용

  • DR 아키텍처 설계: IDC-AWS 하이브리드 구조 기반 DR 아키텍처 설계 및 전환 계획 수립
  • AWS MGN 구성: AWS MGN 에이전트 설치 및 온프레미스 서버 실시간 복제 구성
  • DR 환경 구성: 총 6대(개발 2 + 운영 4) 서버 DR 대상 구성
  • 네트워크 연결: Site-to-Site VPN 기반 IDC-AWS 간 네트워크 연결 구성
  • 보안 그룹 설계: DR 환경용 보안 그룹 및 라우팅 테이블 설계
  • DR 절체 테스트: DR 절체 테스트 시나리오 수립 및 검증 수행, 복구 절차 표준화
  • 결과 문서화: DR 구성 및 테스트 결과 문서화, 운영 기준 정립

기술 스택

클라우드AWS
마이그레이션AWS MGN (Application Migration Service)
네트워크Site-to-Site VPN
보안WAF, GuardDuty, Inspector
서버 OSLinux, Windows Server

6대

BCP 확보
IDC-AWS 하이브리드 DR 환경 구성으로 비즈니스 연속성(BCP) 기반 마련
복구 표준화
DR 절체 테스트 수행 및 복구 절차 표준화로 장애 대응 체계 수립
무중단 복제
AWS MGN 활용으로 온프레미스 환경 무중단 실시간 복제 및 클라우드 전환 완료
