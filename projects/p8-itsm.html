ITSM 시스템
AWS 인프라 아키텍처 구성

역할: 신규 ITSM 시스템 AWS 인프라 설계 및 구축 담당

프로젝트 개요

동화기업 신규 ITSM(IT Service Management) 시스템의 AWS 인프라를 설계하고 구축한 프로젝트입니다. 고가용성과 확장성을 고려한 멀티 레이어 구조를 설계하고, 개발/운영 환경을 분리하여 안정적인 배포 파이프라인을 구축했습니다.

ECS Fargate를 도입하여 컨테이너 기반 운영 환경의 인프라 관리 부담을 최소화하고, AWS CodePipeline 기반 CI/CD를 구성해 배포 프로세스를 자동화했습니다.

아키텍처 구성

VPC 내 2개 가용 영역(AZ) 기반 고가용성 구조로 설계했습니다. 퍼블릭 서브넷에는 ALB(Application Load Balancer)를 배치하고, 프라이빗 서브넷에는 ECS 컨테이너 워크로드를 분산 배치했습니다. 데이터베이스 전용 프라이빗 서브넷에는 Aurora PostgreSQL Writer/Reader 이중화 구성을 적용했습니다.

  • 인프라 아키텍처: ECS/EC2, ALB, Aurora PostgreSQL, S3, Amplify, CodePipeline 활용
  • 고가용성 구조: 2개 AZ 기반 ECS 컨테이너 분산, Aurora Read Replica 구성
  • 환경 분리: DEV / PRD 환경 분리 구성 및 배포 파이프라인 독립 구축
  • CI/CD 자동화: CodePipeline 기반 Docker 이미지 빌드·ECS 배포 자동화
  • 컨테이너 환경: ECS EC2 및 Fargate 기반 컨테이너 운영 환경 구축
  • Docker 표준화: Docker 이미지 빌드·배포 프로세스 표준화
  • 보안: WAF, Ahnlab EPP/CPP/MDS/EDR-V3, 서버 접근제어 적용
  • 모니터링: CloudWatch, X-Ray 기반 애플리케이션 성능 모니터링
