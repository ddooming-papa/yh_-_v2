IDC·클라우드
통합 모니터링 구축

역할: 동화그룹 IDC 및 클라우드 통합 모니터링 환경 구축·운영

프로젝트 개요

기존에는 IDC 서버, AWS, Azure 각각의 모니터링 도구를 개별적으로 확인해야 했습니다. 계정별로 접속하여 현황을 파악하는 방식은 장애 초기 대응 속도를 늦추고 운영 비효율을 야기했습니다.

Zabbix와 Grafana를 핵심 도구로, AWS CloudWatch 및 Azure와 연동하여 IDC·온프레미스·멀티클라우드 환경을 단일 대시보드에서 통합 관제할 수 있는 환경을 구축했습니다. 또한 알람 튜닝을 통해 노이즈를 제거하고, 장애 이벤트를 Teams 및 메일로 자동 통보하는 체계를 완성했습니다.

주요 수행 내용

  • Zabbix 버전 업그레이드: v4.4.5 → v6.0.4로 업그레이드, IDC 서버·네트워크 통합 관제 구성
  • Grafana 통합 대시보드: Grafana와 Zabbix·CloudWatch를 연동하여 멀티클라우드 통합 대시보드 구축
  • 멀티클라우드 관제: AWS CloudWatch·Azure를 Grafana와 연동하여 계정별 개별 접근 없이 전체 현황 즉시 확인 가능
  • 알람 체계 개선: Zabbix 기반 Teams·메일 알람 구성, 포스타 SMS 서비스 대체
  • 알람 최적화: Zabbix 템플릿·Grafana 대시보드 튜닝으로 필수 알람만 수신, 노이즈 제거
  • 계정 통합: Azure AD와 Grafana 연동으로 단일 계정 관리 체계 구축
  • Python 모니터링 스크립트: 자체 제작 Python 스크립트 기반 보조 모니터링 운영

기술 스택

모니터링 서버Zabbix v6.0.4
시각화Grafana (Zabbix, CloudWatch, Azure 데이터 소스 연동)
클라우드 관제AWS CloudWatch, Azure Monitor
알람Zabbix → Teams / 메일 / SMS 자동 알람
계정 통합Azure AD + Grafana SSO 연동
자동화Python (자체 모니터링 스크립트)
